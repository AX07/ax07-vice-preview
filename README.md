# Vice: retro-neon scroll portfolio (concept)

Single-file, no-build page: sunset hero, scroll-driven night drive with a helicopter chase, three story chapters
with GTA-style animated postcards, and a 3D pistol that comes apart into the studio's services (Three.js).
Libraries (GSAP, Lenis, Three.js) load from CDNs. All art is original and drawn in code.

Optional drop-ins: `assets/gta-1.mp4`, `gta-2.mp4`, `gta-3.mp4` play over the three postcards.
Edit the copy, labels (Barrel, Trigger, Magazine, Handle, Sights) and the email link directly in `index.html`.
